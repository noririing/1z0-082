# Oracle Database Administration I 学習Q&A

Oracle Database Administration I（1Z0-082-JPN）の公開されている試験範囲を参考に作成した、個人学習用の1問1答サイトです。

## このサイトについて

- 個人の学習を目的とした非公式コンテンツです。
- Oracle、Oracle University、認定試験提供者とは提携・承認・運営関係にありません。
- 実試験の問題、解答、またはその再現を掲載するものではありません。
- 問題・回答・解説は、公開情報と一般的なOracle Databaseの学習内容をもとに新規作成しています。

## 使い方

1. キーワードまたは分野で問題を絞り込みます。
2. 自分で答えを考えてから「答えを見る」を選びます。
3. 理解できた問題を「学習済みにする」で記録します。

学習済み状況と折りたたみ状態は、利用したブラウザ内にのみ保存されます。個人情報は収集せず、外部サービスへ送信しません。
